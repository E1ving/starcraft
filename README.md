# Starcraft - Python射击游戏

## 项目简介
这是一个基于Python和Pygame开发的2D射击游戏，支持单人和双人模式。玩家控制飞机在太空中与敌机战斗，收集道具，挑战不同难度的关卡。

## 环境配置

### 系统要求
- Python 3.7 或更高版本
- Windows 10/11 或 macOS 或 Linux

### 依赖安装
```bash
pip install pygame
```

## 游戏操作

### 模式选择
- 按 `1` 键：选择单人模式
- 按 `2` 键：选择双人模式

### 单人模式操作
- **移动控制**：WASD键
  - W：向上移动
  - S：向下移动
  - A：向左移动
  - D：向右移动
- **道具使用**：
  - Y：使用炸弹（清除屏幕所有敌机）
  - U：使用子弹补给（获得双发子弹）

### 双人模式操作
- **玩家1**：
  - 移动：WASD键
  - 道具：Y（炸弹）、U（子弹补给）
- **玩家2**：
  - 移动：方向键（↑↓←→）
  - 道具：K（炸弹）、L（子弹补给）

### 游戏功能
- **暂停游戏**：点击右上角暂停按钮或按ESC键
- **重新开始**：游戏结束后点击"重新开始"按钮
- **退出游戏**：游戏结束后点击"结束游戏"按钮

### 游戏机制
- **生命系统**：玩家有3条生命，被敌机或子弹击中会失去生命
- **分数系统**：击毁敌机获得分数，不同敌机分数不同
- **道具系统**：
  - 炸弹补给：增加炸弹数量
  - 子弹补给：增加子弹补给数量
  - 减速补给：暂时降低敌机速度
- **关卡系统**：随着分数增加，游戏难度逐渐提升

### 游戏特色
- 支持单人和双人合作模式
- 多种敌机类型和攻击模式
- 丰富的道具系统
- 动态难度调整
- 像素风格美术设计
- 完整的音效和背景音乐

## 技术特点
- 基于Pygame框架开发
- 使用精灵（Sprite）系统管理游戏对象
- 实现精确的碰撞检测
- 支持多玩家输入处理
- 模块化代码设计

## 注意事项
- 确保游戏目录下所有资源文件完整
- 建议使用耳机体验完整音效
- 双人模式需要键盘支持多键同时按下
- 游戏会自动保存最高分记录
